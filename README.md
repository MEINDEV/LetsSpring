# Backend Mastery: 6-Month Practice Platform

A mentor-led course: Java 21, then Spring Boot 3, then production backend, then microservices.

## How to use
Open this folder in VS Code and chat with Claude. Useful phrases:
| Say | What happens |
|---|---|
| `continue` / `next` | Mentor checks PROGRESS.md and starts your next lesson or task |
| `explain again <topic>` | A different explanation with new examples |
| `hint` | A hint for the current task (hints come in levels; no full answer) |
| `task done` | Mentor runs the tests, reviews your code, and gives a score |
| `quiz me` | Quick quiz on finished topics |
| `status` | Progress summary |

## Files
- [ROADMAP.md](ROADMAP.md): the full 26-week syllabus
- [PROGRESS.md](PROGRESS.md): your progress tracker (updated by the mentor)
- [SETUP.md](SETUP.md): Week 0 installation guide
- [CLAUDE.md](CLAUDE.md): mentor instructions (loaded automatically each session)
- `weeks/`: lessons, examples and tasks, created week by week
- `projects/`: capstone projects
